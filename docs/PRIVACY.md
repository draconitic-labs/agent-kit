# Draconitic Agent Kit privacy

Version 0.1.0. Publisher: Draconitic Labs; support@draconitic.com.

The Workbench scripts process explicitly selected files locally. They contain no network client or telemetry. Evidence bundles copy file contents; manifest and snapshot reports can contain supplied values and filenames. Output remains at the location chosen by the user until the user deletes it. Review inputs and outputs before publication. These tools do not automatically redact secrets or personal information.

The Agents plugin sends tool arguments over HTTPS to agents.draconitic.com. Use public search terms, public claim text, record IDs and citation URLs. The existing service processes these queries against its curated corpus. Network infrastructure can receive request metadata such as the client's IP address. This adapter does not create an account, fund credit, grant spending authority, or persist a query history of its own.

Product adapters invoke separately installed products. Their own policies and terms apply, including Proscenium license validation when its Pro features are used. This kit does not include either product's proprietary implementation.

The host agent may read the inputs and outputs into model context under the host provider's policy. Local processing by these scripts does not prevent the host from transmitting model context. No plugin asks for credentials or personal information. Contact support to ask about data handling or report an accidental disclosure; never send credentials in a report.

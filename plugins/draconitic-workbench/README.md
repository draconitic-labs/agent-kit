# Draconitic Workbench

Three local tools for agents: explicit-file evidence bundles, extension manifest review and typed JSON snapshot comparison. Python 3.10+; standard library only. Scripts run only when the agent invokes them. They make no network requests, install no hooks and change no harness permissions.

Each skill is self-contained; its `SKILL.md` gives the commands. Snapshot arrays are compared by index. Files stay on the computer unless the host agent or the user uploads them. See `PRIVACY.md` and `TERMS.md`.

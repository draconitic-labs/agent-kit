# Draconitic Agents

Connects the public Draconitic evidence service at https://agents.draconitic.com/mcp. Six read tools expose dated corpus search, package identity evidence, dataset discovery, revision history, citation membership and exact claim-span checks. The public tools need no sign-in. Public service limits apply.

The connection sends tool arguments to Draconitic Labs, so use public queries rather than private documents or credentials. A package missing from the corpus returns unknown. The plugin has no payment, account or spending workflow.

See the bundled `draconitic-public-evidence` skill, `PRIVACY.md` and `TERMS.md`. Support: support@draconitic.com · https://draconitic.com

# Draconitic Agents

Connect the existing public Draconitic evidence service at https://agents.draconitic.com/mcp. Six read tools expose dated corpus search, package identity evidence, dataset discovery, revision history, citation membership and exact claim-span checks. No sign-in is required for these public tools. Public service limits apply.

The connection sends tool arguments to Draconitic Labs. Use public queries, not private documents or credentials. A missing package returns unknown. Citation membership and claim matching do not independently establish truth. This plugin contains no payment, funding, account or spending workflow.

See the bundled `draconitic-public-evidence` skill, `PRIVACY.md` and `TERMS.md`. Support: support@draconitic.com · https://draconitic.com

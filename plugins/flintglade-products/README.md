# Flintglade Product Adapters

Skills for existing Greenlit Goods feed preflight and Proscenium local webhook scenarios. Install the relevant product separately under its own terms. This package contains instructions only; it does not grant Pro entitlements, include proprietary binaries or install software automatically.

Both skills inspect the installed command's help before running it. Greenlit writes repairs to a new output. Proscenium sends synthetic requests only to a user-owned local receiver and requires its own license for headless scenario runs.

See each skill's `SKILL.md`, `PRIVACY.md` and `TERMS.md`. Support: support@draconitic.com · https://draconitic.com

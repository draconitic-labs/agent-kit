# Flintglade Product Adapters

Skills for Greenlit Goods feed preflight and Proscenium local webhook scenarios. Install the product separately under its own terms. This package contains instructions only and installs no software.

Both skills read the installed command's help before running it. Greenlit writes repairs to a new file. Proscenium sends synthetic requests only to a receiver on the local machine and needs its own licence for headless scenario runs.

See each skill's `SKILL.md`, `PRIVACY.md` and `TERMS.md`. Support: support@draconitic.com · https://draconitic.com
